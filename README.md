---

## 🎨 Design & Tech Stack
- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS
- **Typography**: Plus Jakarta Sans (Modern headings) + Inter (Clean body)
- **Palette**: Soft teal-sage `#5A9E91`, warm off-white `#FAF8F5`, mint tint `#F3F8F6`, slate deep `#1E293B`
- **Mobile First**: Optimized touch interactions, sticky action bar (Call, WhatsApp, Book)
